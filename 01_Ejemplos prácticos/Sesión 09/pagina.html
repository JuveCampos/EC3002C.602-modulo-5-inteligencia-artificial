¿Qué es el web scraping?

El web scraping es la técnica de extraer información de páginas web de forma automatizada. Suele apoyarse en herramientas o librerías que descargan HTML, lo analizan (parseo) y luego transforman el contenido en estructuras de datos analizables como tablas.

Antes de extraer datos, es buena práctica revisar el archivo robots.txt del sitio y sus Términos de Servicio, respetar los límites de uso y no saturar los servidores. También conviene registrar la fuente y la fecha de captura de la información para asegurar trazabilidad.

En el ecosistema de datos, el scraping se complementa con APIs oficiales, datasets abiertos y técnicas de limpieza. En R, librerías como rvest o httr2 son comunes; en Python, requests, BeautifulSoup o Scrapy son muy utilizadas.

Bloque de código de ejemplo

Nota: Este es un ejemplo meramente didáctico en pseudocódigo/JavaScript para ilustrar selectores y pausas entre peticiones.

// Ejemplo didáctico (Node.js + fetch):
import fetch from "node-fetch";
import cheerio from "cheerio"; // para parsear HTML

const delay = (ms) => new Promise(r => setTimeout(r, ms));

async function scrapeListado(urlBase, paginas=3){
  const resultados = [];
  for(let p=1; p<=paginas; p++){
    const url = `${urlBase}?page=${p}`;
    const res = await fetch(url, { headers: { 'User-Agent': 'DemoScraper/1.0' }});
    const html = await res.text();
    const $ = cheerio.load(html);

    $("article.card").each((_,el) => {
      const titulo = $(el).find("h2 a").text().trim();
      const link = $(el).find("h2 a").attr("href");
      const fecha = $(el).find("time").attr("datetime");
      resultados.push({ titulo, link, fecha });
    });

    // Espera entre solicitudes para no saturar el servidor
    await delay(1500);
  }
  return resultados;
}

scrapeListado("https://ejemplo.test/blog").then(console.log);

También puedes hacerlo en R con rvest o en Python con BeautifulSoup. La lógica es parecida: descargar HTML, extraer nodos por selectores y convertir a tabla.

Recursos útiles

  • rvest (R) — Scraping con selectores CSS/XPath en R.
  • BeautifulSoup (Python) — Parseo de HTML y navegación por nodos.
  • Scrapy (Python) — Framework robusto para rastreadores y canalizaciones.
  • MDN HTML — Referencia de las etiquetas HTML.

Si compartes resultados públicamente, incluye siempre créditos y enlaces a la fuente de los datos.

Más párrafos de ejemplo

El scraping es útil para prototipos y exploraciones rápidas. Sin embargo, si el sitio ofrece un endpoint de API, usarlo suele ser más estable y escalable. Además, los contratos de servicio de las APIs especifican límites y condiciones claras.

Para mantener trazabilidad, conviene almacenar en tu base de datos la URL original, hash del HTML, marcas de tiempo y versión del parser. Así puedes reproducir resultados y depurar cuando el DOM cambie.
